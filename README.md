# 装备合成原型

原创竖屏自动战斗小游戏。保留“关卡掉装备 → 背包穿戴 → 5 件同品质装备合成 1 件高品质装备 → 强化 → 继续挑战”的核心循环。Cocos Creator 与网页试玩使用同一份 `assets/scripts/core/game-core.ts` 规则。

## 当前可试玩内容

- 三个主线章节、30 个逐步开放的关卡，包含伏击、护甲、恢复、元素伤害和半血狂暴等敌人行为。第 10、20、30 关分别有蓄力重击、恢复、护甲狂暴首领；破甲、淬毒及生存技能可以应对对应机制。
- 章节页可预览敌人、机制、应对提示和掉落品质概率，保存失败挑战的最高推进。每五关一个通关宝箱，提供五件同部位装备和资源，直接衔接五合一合成；每个宝箱只能领取一次。
- 6 个装备位、5 档品质、随机基础属性与少量附加词条，背包比较、穿戴和锁定。
- 5 合 1 装备合成；同部位材料保留产物部位，锁定或已穿戴装备不能消耗。
- 装备强化至 +10、战力计算、浏览器本地存档。
- 营地包含体力恢复（每 5 分钟 1 点）、最多 8 小时离线收益、每日委托、三类永久训练。装备词条参与战斗，背包最多 100 件，多余战利品转为铁矿。
- Cocos 装备页可分解未锁定装备；旧版存档升级后保留装备与资源。
- Cocos 挑战逐步播放各波战斗，显示血条、普攻/技能、暴击和恢复；支持两档速度、刷新续播及结算转装备，续播不会重复发奖。
- Cocos 装备详情提供换装比较、基础范围、重铸、单词条洗练和同部位强化继承。重铸石从第 3 关起掉落，洗练尘从第 5 关起掉落；候选结果可选择保留或采用，并能跨刷新恢复。
- 冒险页可进入金币、铁矿、重铸石、洗练尘、宝石五类材料副本，每类三档难度、每日三次；通关后可扫荡。敌人具有伏击、护甲、灼烧、恢复或碎晶重击机制。
- 装备页可进入宝石工坊：三类属性、五个等级、同类同级五合一、镶嵌/免费卸下、第二孔开启。宝石随装备保留，带宝石的装备合成/分解前必须先卸下宝石。
- 营地可研习六种技能：伤害、治疗、破甲、减伤、持续毒伤和增伤；主线首通提供技能点，升级有前置条件。两套三格装配方案独立保存，技能按行动次数分别冷却，可花费 100 金币重置并返还技能点。
- 三张临时美术资源：主角、怪物和战斗背景。画风后续会整体重做。

## Cocos Creator 3.8.8

用 Creator 打开本目录中的 `assets/Main.scene`，点击顶部预览即可试玩。该场景已挂载 `StarforgeGame`，设计分辨率为 420×840。冒险、装备、合成三页共享 `assets/scripts/core/game-core.ts` 的规则。

要更新 GitHub 网页预览，在 Creator 的“发布到 → 终端 → Web 手机端”中构建，然后于项目根目录运行：

```text
npm test
npm run export:cocos-web
```

构建产物位于 `build/web-mobile`；导出命令将其复制到提交入库的 `docs`。GitHub Actions 执行规则测试后，把 `docs` 发布到 GitHub Pages。`web` 是独立的轻量浏览器调试页，发布版本以 Cocos 构建为准。

首次打开工程后可在 Creator 的“发布到 → 应用 → 微信小游戏”中创建微信构建配置。微信包及微信开发者工具联调尚未完成；网页预览通过后再验证平台接口、包体和触控体验。

## 边界

当前仍在持续开发。长期挑战、宠物、竞技场、广告与付费未实现；长期成长数值和正式美术仍需完善。锻造、宝石、技能研习和材料副本交互已在 Cocos 主版本实现，独立的 `web` 调试页尚未提供这些入口。网页存档和微信小游戏存档各自独立；需要跨端继承时再增加账号及云端存档。

完整游戏开发清单及已验证范围见 [DEVELOPMENT.md](DEVELOPMENT.md)。`node tools/simulate-progression.mjs 1 10` 可复现十个种子的首小时自动成长诊断；它只调用游戏规则、不注入资源，不能代替真人试玩。诊断样本见 `validation`。当前是持续开发版本，尚未完成成熟游戏验收。
